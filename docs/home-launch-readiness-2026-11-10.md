# Homepage and local launch-readiness handoff — 10 November 2026

Following the user's further design review, the homepage city-image grid was removed. The full-bleed hero now uses an optimized derivative of Talay's own developer-supplied villa render and links to the Talay record. A second architectural image is identified and linked to its own Yas Riva Reserve project. Featured projects use their own reviewed images and are arranged as one larger and two smaller landscape views. Property-type links navigate to the real filtered catalogue; all seven emirates remain available in the search and navigation. Developer count, property types and latest journal stories come from site data. A project render is not a photograph of a completed building. Photographs still used in navigation retain their existing credits at `/privacy#image-credits`.

The Talay hero and large Rivage source have smaller derivatives. Featured image variants are used only when the catalogue still points at the exact corresponding original; other sources fall back to the normal image pipeline. The pre-optimized journal images and those variants are served directly, while below-the-fold images remain lazy loaded. Desktop, tablet and 320px/390px mobile layouts were inspected. Search, property-type links, city switching, shortlist, comparison, enquiry drawer and mobile journal navigation were tested locally; automated accessibility scans reported no violations in the checked desktop, mobile and dark-mode views. These checks do not establish real email delivery or replace testing on physical devices.

Catalogue and developer listing cards now receive a compact projection rather than full research records and the complete image registry. Search supports a project/developer keyword and catalogue-derived property types, including mixed types. Same-route city navigation and header search update the URL and filters without another catalogue RSC request. Save and comparison use stable project IDs for the reviewed public collection; the four earlier comparison slugs map to their owned IDs.

In a local production comparison, decoded `/projects?emirate=Dubai` HTML fell from 5,012,663 to 571,760 bytes (about 89%). Median warm local response time across three samples fell from 961 ms to 195 ms; Abu Dhabi fell from 845 ms to 110 ms. Emaar's developer page decreased from 1,191,923 to 296,315 decoded bytes. These are local measurements, not guarantees of live-network performance. Evidence: `artifacts/home-redesign/production-performance-comparison.json`.

All 575 reviewed, sourced project URLs now appear in the sitemap. Project metadata allows indexing only for this public collection on a configured public origin; the local preview remains noindex. No public deployment or Git push was made.

## Remaining launch checks

- The local environment has no configured SMTP delivery. The enquiry UI was tested with a mocked response and persistence/validation unit tests; no real email or CRM delivery has been verified. Production requires the correct private email/CRM configuration and an end-to-end delivery check. Filesystem-backed enquiry storage and the in-process rate limiter require durable shared storage and a distributed limiter on serverless or multi-instance hosting.
- Set `NEXT_PUBLIC_SITE_URL` to the actual public HTTPS origin at build time; local preview defaults to localhost and is intentionally noindex. Verify robots, sitemap and canonicals on the chosen host.
- Direct project requests from a social crawler return the correct single project Open Graph image. During Next.js client-side navigation the previous route's default Open Graph tags can remain alongside the project tags in the browser DOM; this framework behaviour was observed in both the old and updated preview and needs further investigation before asserting that every JavaScript-rendered crawler sees a single image.
- The 200 journal publication dates are owner-requested backdates and do not establish historical publication. See `docs/journal-long-tail-100-handoff.md` and Google publication-date guidance before release. Recheck time-sensitive market, fee, ownership, mortgage and visa content with official sources before publishing.
- Physical device, external network and real hosting performance have not been measured. The user confirmed public asset distribution rights and Git LFS quota/budget on 8 November; the target hosting environment still needs to be determined. The user asked to review locally first; do not push or deploy without their direction.
